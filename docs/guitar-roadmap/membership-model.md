# Guitar Roadmap Membership Model

The One Guitar Roadmap 的 Free / Plus / Pro 不以「解鎖多少影片」作為主要差異。

核心分級原則：

> Free 給方向。  
> Plus 給系統。  
> Pro 給結果。

學生真正購買的是：

> 我離目標更近的確定性。

---

# Free — Explore

## Student Mindset

「我想先看看。」

## Core Promise

幫學生：

- 找到自己在哪裡
- 看見完整學習方向
- 理解 The One 的教學方法
- 第一次感受到有系統的吉他學習

## Free 解決的是

Knowing

「我開始知道問題在哪裡。」

## Suggested Features

- 完整 Roadmap 可視化
- Level 0 基礎定位
- 精選公開教學
- 部分教材／圖解
- 部分練習體驗
- 基礎進度
- 學習成果展示
- 免費卡關資源
- 公開內容

## CTA

> 先找到我的位置

---

# Plus — Commit

## Student Mindset

「我願意自己練，但我要一套完整的方法。」

## Core Promise

給學生完整：

- 學習路線
- 教學內容
- 練習
- 應用
- 進度
- 複習

## Plus 解決的是

Practicing

「我知道每天應該怎麼練。」

## Suggested Features

- 完整 Roadmap
- 完整教學課程
- 完整圖解教材
- 練習音檔
- 伴奏音檔
- 10 / 20 / 40 分鐘練習菜單
- 完整卡關支線
- Review / Recall 系統
- 作業功能
- 完整進度
- 階段 Challenge
- 階段考核資格
- 會員社群
- Live Q&A

Plus 的人力 Review 可以：

- 有限提供
- 活動提供
- 額外加購
- 後續依成本再調整

Review quota 不應過早寫死。

## CTA

> 開始系統訓練

---

# Pro — Achieve

## Student Mindset

「我不想再自己摸索。」

## Core Promise

有人確認：

> 我真的學會了。

## Pro 解決的是

Achieving

「我不只是有練，而是真的走到成果。」

## Suggested Features

包含所有 Plus 功能，另外增加：

- 老師 Review
- 作業批改
- 個別學習建議
- 卡關人工介入
- 個人化練習調整
- 階段通關判定
- 優先 Q&A
- 優先審核
- 完成認證
- 1-on-1 優先預約或加購

Pro 的真正差異不是更多影片，而是：

> Human Verification + Accountability

---

# Upgrade Philosophy

升級應發生在學生真正有需求的時刻。

例如：

學生完成自我挑戰後：

> 你認為自己已經通過。  
> 想讓老師確認你的節奏與穩定度是否真正達標嗎？

→ Pro Review

學生長時間沒有練習：

> 最近比較忙嗎？  
> 我們可以依照你現在的時間重新安排本週練習內容。

→ Pro Coaching

學生完成抓歌：

> 你已經完成自己的判斷。  
> 想讓老師確認抓出的和弦是否正確嗎？

→ Pro Review

學生卡關：

> 你已經在這個能力停留一段時間。  
> 是否需要老師協助判斷真正卡住的原因？

→ Pro Support

# Pricing Principle

此文件不固定實際價格。

定價未來應依：

- 內容成本
- Review 人力成本
- 老師成本
- 使用率
- 續訂率
- 學生成果
- 市場回饋

持續調整。

不得因目前方便開發，而過早把商業規則寫死。
